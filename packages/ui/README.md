# `packages/ui`

Shared MIT-licensed design system built on [`cosscom/ui`](https://github.com/cosscom/ui) (`@base-ui/react` + Tailwind CSS v4), Inkade domain patterns (`ProseMirrorOutlineEditor`, `ArticleReader`, `ArticleEditor`, `DiffViewer`, `ScopeTreePicker`), and Tiptap editor extensions (including the inline `AdeThreadChip` node view).

Reused across `@inkade/views`, `apps/web`, and embedded host web panels. See [`docs/UX-DESIGN-SYSTEM.md`](../../docs/UX-DESIGN-SYSTEM.md) and [`docs/INTEGRATION-GUIDE.md`](../../docs/INTEGRATION-GUIDE.md).
