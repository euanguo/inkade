# `apps/web`

React 19 + Vite + TanStack Router/Query + Tailwind v4 + `cosscom/ui` (`@base-ui/react`) + Tiptap workspace:
- **Daily Outline View**: keyboard-first outliner with zoom-in, yesterday rollover, drag-and-drop, `[[wikilink]]` preview, inline `AdeThreadChip` badges, and one-click ADE dispatch
- **Library & Article Reader/Editor View**: distraction-free long-form reader (synced TOC, Shiki, Mermaid lightbox, wide tables, agent update Diff bar, highlight-to-ask toolbar, backlinks) and dual-mode Tiptap/Markdown editor
- **Inbox**: web clips and quick-captured notes ready for triage or agent synthesis
- **Threads Console & Scope Admin**: unified ADE conversation control tower and visual Scoped Token / Project Scope Rule manager
- **Mobile-first responsive PWA** with bottom `+ Quick Capture` drawer
